# Repository language rule / Règle de langue / Regla de idiomas

All future user-facing changes in this repository must ship in French, English, and Spanish in the same change. This includes UI copy, errors, onboarding, examples, generated default text, and user-facing documentation. When changing an existing document, update the affected passage in all three languages; untranslated legacy passages may remain until touched. Keep product names, code identifiers, captured screen text, and user-authored content as-is. Do not machine-translate user data or change an artifact's language silently.

Toute évolution destinée aux utilisateurs de ce dépôt doit être livrée simultanément en français, anglais et espagnol : interface, erreurs, prise en main, exemples, textes générés par défaut et documentation publique. Lorsqu’un document existant est modifié, traduire le passage concerné dans les trois langues ; les passages historiques non touchés peuvent attendre. Conserver tels quels les noms de produits, identifiants de code, textes capturés à l’écran et contenus rédigés par l’utilisateur. Ne pas traduire automatiquement les données utilisateur ni changer silencieusement la langue d’un artefact.

Todo cambio dirigido a usuarios de este repositorio debe entregarse al mismo tiempo en francés, inglés y español: interfaz, errores, primeros pasos, ejemplos, textos predeterminados generados y documentación pública. Al modificar un documento existente, actualizar el pasaje afectado en los tres idiomas; los pasajes anteriores no modificados pueden esperar. Conservar los nombres de productos, identificadores de código, texto capturado en pantalla y contenido escrito por el usuario. No traducir automáticamente los datos del usuario ni cambiar silenciosamente el idioma de un artefacto.

Implementation checklist: add FR/EN/ES entries to `studio/i18n.js` for UI changes; preserve placeholder names across languages; verify all three languages in browser tests for affected flows; add/adjust package-level localization for generated artifacts when applicable; run `npm test`, `npm run test:browser`, and `npm run format:check`. No user-facing feature is complete with only one or two languages.
